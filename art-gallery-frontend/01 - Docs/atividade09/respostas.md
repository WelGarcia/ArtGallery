# Atividade 09 — Respostas da Seção 1

O **401** indica que não estou autenticado, o **403** que estou logado, mas não tenho permissão para mexer na obra de outra pessoa, e o **404** que a obra não existe. Primeiro verificamos a existência para não tentar autorizar algo que não foi encontrado. Ao editar ou excluir uma obra, atualizamos o banco antes de apagar a imagem: se fizéssemos o contrário e o banco falhasse, a obra ficaria cadastrada com a imagem quebrada. Um **arquivo órfão** é uma imagem salva sem registro correspondente, como numa publicação com título vazio ou numa tentativa de trocar a imagem de outra pessoa. O `errorHandler.js` limpa esses arquivos quando a requisição falha. O botão Excluir precisa ficar fora do link que abre o detalhe para não misturar os cliques; e o modal fica fora do card para cobrir a tela corretamente. Esconder o botão Editar também não garante segurança, pois alguém pode acessar a URL diretamente; a API precisa conferir quem é o dono.
