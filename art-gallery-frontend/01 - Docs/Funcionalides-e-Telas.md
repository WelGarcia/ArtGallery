# Funcionalidades e Telas

| Funcionalidade | Tela equivalente |
|---|---|
| Landing / página inicial | `LandingView.vue` |
| Cadastro e autenticação | `auth/LoginView.vue`, `auth/RegisterView.vue` |
| Exploração do conteúdo | `GalleryView.vue` |
| Dashboard administrativo | `admin/AdminDashboardView.vue` |
| Gerenciamento de usuários (admin) | `admin/AdminUsersView.vue` |
| Gerenciamento do conteúdo principal (admin) | `admin/AdminGalleryView.vue` |
| Rota não encontrada | `NotFoundView.vue` |
